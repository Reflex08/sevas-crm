1 · Create the Meta app (one time)

Go to developers.facebook.com/apps → Create App → use case Other → type Business → name it Sevas CRM.
Then App settings → Basic: copy the App ID and App Secret (click Show) into step 3 below. Leave the app in Development mode — that is all your own Page needs.

2 · Point its webhook here

In the app: Add product → Webhooks → choose Page → Subscribe to this object:
Callback URL:
Verify token:
Click Verify and save, then tick leadgen in the field list and Subscribe.

3 · Get a login token and connect

Open Graph API Explorer → pick Sevas CRM as the app → under Permissions add pages_show_list, pages_manage_metadata, pages_read_engagement, leads_retrieval → Generate Access Token → log in, allow, choose your Page → copy the token.

4 · Test it

Lead Ads Testing Tool → pick your Page + form → Create lead. It shows up in the CRM Leads tab within a minute as New · Meta Ads. Delete that test lead afterwards.
